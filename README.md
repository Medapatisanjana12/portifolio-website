# Sanjana Medapati Portfolio

Professional developer portfolio for AI/ML Engineer, Software Developer, Data Analyst, internship, and placement opportunities.

## Features

- Modern responsive portfolio built with React, Vite, Tailwind CSS, and Framer Motion.
- Recruiter-focused hero section with resume, GitHub, LinkedIn, and contact actions.
- Light and dark mode with persisted user preference.
- Sections for About, Skills, Experience, Projects, Certifications, Achievements, Education, GitHub Contributions, and Contact.
- Project cards with previews, impact statements, tech badges, GitHub links, and live demo links.
- Downloadable resume from the public assets folder.
- SEO metadata, accessible focus states, reduced-motion support, and optimized static build output.

## Tech Stack

- React
- Vite
- Tailwind CSS v4
- Framer Motion
- React Icons
- JavaScript
- GitHub Pages compatible static build
- Vercel or Netlify compatible static deployment

## Installation

```bash
npm install
```

## Local Development

```bash
npm run dev
```

The configured local URL is:

```bash
http://localhost:3000
```

## Production Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Deployment

### Vercel or Netlify

Use these settings:

- Build command: `npm run build`
- Publish directory: `dist`
- Environment variables: none required

### GitHub Pages

The project also includes:

```bash
npm run deploy
```

For GitHub Pages subpath deployment, set:

```bash
VITE_BASE_PATH=/portifolio-website/
```

## Live Deployment

Deployment URL: add the final Vercel, Netlify, or GitHub Pages URL after publishing.
